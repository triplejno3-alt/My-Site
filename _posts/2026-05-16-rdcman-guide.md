> 运维几十台 Windows 服务器，桌面上开了二三十个 mstsc 窗口。
> 想找其中某一台，得一个个点过去看标题栏。

这可能是每个 Windows 运维人员都经历过的噩梦。当你管理的服务器数量从三五台变成三五十台时，系统自带的远程桌面连接（mstsc）就开始变得力不从心：每个连接一个独立窗口，没有分组、没有概览、没有统一的凭据管理。

这就是 RDCMan（Remote Desktop Connection Manager）要解决的问题。

## 一、一段不平凡的历史

RDCMan 是微软 **Sysinternals** 工具集的一员，由 **Julian Burger** 开发。说起 Sysinternals，用过 Windows 的人应该不陌生——Process Explorer、Regmon、Filemon、Autoruns……这些经典工具都是这个团队的杰作。

RDCMan 的诞生时间比很多人想象的要早。在微软 **2006 年收购 Sysinternals** 之前，它就已经存在于 Sysinternals 的工具库中，是许多系统管理员私藏的"瑞士军刀"之一。收购之后，它和其他 Sysinternals 工具一样归于微软旗下，继续更新维护。

此后的十几年里，RDCMan 一直低调而稳定地存在于 Sysinternals 工具集中，没有太多宣传，却在 Windows 运维圈子里口口相传。用过的人都知道它的好——直到 2023 年，一场风波打破了这种平静。

那一年，RDCMan 被曝出安全漏洞，涉及凭据存储的加密强度问题。微软一度将其从官方下载页面**下架**，社区一片哗然。许多依赖 RDCMan 管理数十台服务器的运维人员纷纷表示"无法接受"。好在微软最终听取了社区的声音，修复了安全问题后重新上架，并且在后续版本中持续改进。

**2026 年 2 月 4 日**，微软发布了 **RDCMan v3.12**，文件大小 116.1 MB，支持 Windows 11 及 Windows Server 2016 以上的系统。

一个从 Sysinternals 时代走来、经历过下架风波又归来的工具——这本身就说明了它的价值。

## 二、RDCMan 到底是什么

简单说：**RDCMan 是远程桌面连接的资源管理器。**

它把 Windows 自带的 mstsc 从一个"单窗口单连接"的工具，变成了一个"一个窗口管理所有连接"的集中控制台。你可以把服务器按环境分组（生产、测试、开发），为不同组设置不同的登录凭据，用一个缩略图视图同时监控所有服务器的桌面画面。

下载也很简单：

- 官方 ZIP 包：<https://download.sysinternals.com/files/RDCMan.zip>
- 直接运行：<https://live.sysinternals.com/RDCMan.exe>

**绿色免安装**，解压即用，放在 U 盘里也能跑。

## 三、10 分钟快速上手

### 3.1 创建第一个组

打开 RDCMan，右键左侧树形区域 → **Add Group**。

按你的实际环境来划分组，比如：

```
📁 我的服务器
 ├── 📁 生产环境
 ├── 📁 测试环境
 └── 📁 开发环境
```

组可以任意嵌套，但同一个组内不能同时包含子组和服务器。

### 3.2 添加服务器

在某个组上右键 → **Add Server**，输入服务器的主机名或 IP。

但真正好用的是**批量添加**。如果你有 20 台 Web 服务器叫 `web01` 到 `web20`，在组属性里这样写：

```
web[01-20]
```

RDCMan 会自动展开成 20 台服务器。还可以组合使用：

```
{web,db,app}[01-05]
```

一键生成 15 台服务器。这就是效率。

### 3.3 保存配置

第一次配置好后，**File → Save As**，保存为 `.rdg` 文件。这个文件就是你整个服务器拓扑的配置文件，可以复制、分享、备份。

下次换个电脑，只要加载这个 .rdg 文件，你的所有服务器分组和配置就全回来了。

## 四、核心功能详解

### 4.1 分组管理的核心：继承

RDCMan 最强大的设计是**继承机制**。

你在父组上设置好的凭据、显示参数、网关配置，会自动应用到它下面的所有子组和服务器。这意味着：**修改一次密码，几十台服务器全部生效。**

想象一下这个场景：你的实验室账号密码每 90 天要更换一次。没有 RDCMan 的时候，你得逐个打开每个服务器的 RDP 文件修改凭据。有了 RDCMan，你只需要在组属性的凭据配置里改一次。

这就是继承的力量。

### 4.2 凭据管理

凭据有三种保存方式：

| 方式 | 说明 | 适用场景 |
|------|------|---------|
| **组继承** | 凭据从父组传到子组 | 统一管理同一环境的账号 |
| **凭据配置文件** | 全局或文件级存储的凭据模板 | 跨组共享同一套凭据 |
| **Connect As（Shift+Enter）** | 临时使用不同凭据连接 | 偶尔用管理员账号排查问题 |

密码存储方面，RDCMan 支持两种加密方式：
- **CryptProtectData**：基于当前 Windows 登录用户的凭据加密，最简单
- **X509 证书加密**：用证书加密，适合需要跨用户共享 .rdg 文件的团队场景

域字段还支持变量：
- `[server]` — 自动替换为服务器名
- `[display]` — 自动替换为显示名

这在每台服务器都用本地管理员账号的场景下特别有用。

### 4.3 批量导入服务器

除了模式语法，还可以从文本文件导入。每行一个服务器名：

```
web01
web02
db01
db02
...
```

在组属性中选择 **Import from text file** 即可。

### 4.4 虚拟组

这是 RDCMan 里的一个隐藏宝藏。在左侧树形图底部，有一些特殊的**虚拟组**，它们不是由你手动创建的，而是由 RDCMan 自动维护的：

- **Connected** — 所有当前已连接的服务器自动出现在这里，方便你快速查看正在维护哪些机器
- **Reconnect** — 把服务器拖入这个组，它会在这个会话断开后持续尝试重连。非常适合服务器重启升级的场景——你执行完重启命令，它自动连回来
- **Favorites** — 跨组收藏你最常用的服务器
- **Recent** — 最近连接记录

### 4.5 缩略图视图

这是 RDCMan 最直观的功能。选中一个组，右侧面板会以缩略图形式展示该组内所有已连接服务器的实时桌面画面。

你可以为不同服务器设置不同的缩放比例，比如把关键服务器的比例设为 3 或 5，缩略图大到可以直接在预览画面里操作。非关键服务器保持小缩略图，节省屏幕空间。

## 五、实用技巧

### 快捷键大全

| 快捷键 | 功能 |
|--------|------|
| **Enter** | 连接选中的服务器 |
| **Shift+Enter** | 以不同凭据连接（Connect As） |
| **Alt+Enter** | 打开服务器/组属性 |
| **Ctrl+F** | 搜索服务器（支持正则） |
| **Ctrl+Alt+Break** | 全屏切换 |
| **Delete** | 删除选中的服务器或组 |

### 自动重连大法

需要给服务器打补丁重启？右键服务器 → **Add to Reconnect Group**，然后执行重启命令。RDCMan 会在服务器重启后自动重新连接，你甚至不需要盯着进度条。

### 命令行快速连接

不想打开配置好的 .rdg 文件？直接命令行运行：

```cmd
RDCMan.exe /c server1,server2,server3
```

适合临时需要连几台机器看看状态的场景。

### 团队共享配置

把 .rdg 文件放在共享目录里，团队共用一份配置。配合 X509 证书加密凭据，每个人都可以用自己的证书打开凭据。

注意：RDCMan v3.12 保存的 .rdg 文件与旧版本不兼容。如果你打开过旧的 .rdg 文件并保存，原始文件会自动备份为 `filename.old`。

## 六、RDCMan vs mstsc

| 功能 | RDCMan | mstsc（Windows 自带） |
|------|--------|---------------------|
| 多连接管理 | ✅ 树形分组，一目了然 | ❌ 每个连接独立窗口 |
| 批量操作 | ✅ 一键连接/断开整组服务器 | ❌ 需逐个操作 |
| 凭据继承 | ✅ 父组传递，一处修改全局生效 | ❌ 每个 RDP 文件独立保存 |
| 凭据安全存储 | ✅ 加密存储，支持证书 | ❌ 仅存于 .rdp 文件 |
| 实时监控 | ✅ 缩略图视图，同时看所有桌面 | ❌ 不支持 |
| 自动重连 | ✅ Reconnect 虚拟组 | ❌ 需手动重连 |
| 批量导入 | ✅ 模式语法、文本导入 | ❌ 手动逐台添加 |
| 服务器搜索 | ✅ Ctrl+F 正则搜索 | ❌ 不支持 |
| 便携性 | ✅ 绿色免安装 | ✅ 系统自带 |
| **最适合** | **管理大量服务器** | **临时连接一两台** |

## 七、注意事项

1. **缩略图焦点**：已连接的服务器在缩略图视图中可能接收键盘焦点，操作时留意当前焦点位置
2. **网关地址必须用 FQDN**：使用 TS Gateway 时，网关服务器必须填写完全限定域名，否则可能报错 50331656
3. **分辨率上限**：RDP ActiveX 控件有 4096×2048 的硬分辨率限制
4. **修改显示设置后需断开重连**：变更远程桌面尺寸后，必须断开连接再重新连接才能生效
5. **旧系统兼容**：Windows 7/Vista 之前的系统需要 Terminal Services Client v6
6. **自动登录策略**：如需自动登录，需在组策略中禁用"始终提示密码"，路径：计算机配置 → 管理模板 → Windows 组件 → 终端服务 → 加密和安全
