> 在陆地上开车，你有导航、有路标、有红绿灯。
> 在大海上，船什么都没有——除了 AIS。

想象你是一艘正在横跨太平洋的货轮船长。四面是茫茫海水，你既看不到目力以外的船，也喊不到几十海里外的人。你怎么知道前方有没有迎面驶来的巨轮？你怎么知道哪里有浅滩或事故？

这套系统叫做 **AIS（Automatic Identification System，船舶自动识别系统）**。它就像是海上交通的"雷达 + 微信 + 朋友圈"合一体，让每一艘船都能实时知道附近有哪些船、它们要去哪、叫什么名字。

---

## 一、AIS 到底在做什么？

### 最基本的功能：广播自己

每一艘配备 AIS 的船舶，都在**自动地、不间断地**向周围广播一条消息。这条消息包含：

| 信息 | 说明 |
|------|------|
| **MMSI** | 船舶的唯一身份 ID（9 位数字，像船的"身份证号"） |
| **船名** | 你的船叫什么 |
| **位置** | 当前的经纬度 |
| **航速** | 节（海里/小时） |
| **航向** | 船首指向的方向 |
| **目的港** | 你要去哪里 |

这些信息不是人手动填的——大部分都是传感器自动读取。但有一个关键点要搞清楚：

> **AIS 设备本身不具备定位能力。**

它没有 GPS 芯片，没有北斗模块。AIS 的位置信息来自外接的 **GNSS 接收器**（GPS、北斗、GLONASS 等）。AIS 只是把从 GNSS 那里拿到的坐标，编进广播消息里发出去。

打个比方：**GNSS 是"我在哪"，AIS 是"告诉大家我在哪"。**

>

### 核心意义：让船之间互相知道

AIS 不是给船长"导航"用的——导航用 GNSS 就够了。AIS 解决的是另一个问题：**让船知道附近还有其他哪些船。**

一艘 30 万吨的油轮从 15 节（约 28 km/h）减速到完全停止，需要 2 公里以上的刹车距离。在茫茫大海上，等到你用肉眼看到对面来船的时候，已经来不及了。

AIS 让你在看得到对方之前，就已经知道对方的存在。

## 二、船与船之间怎么通信？

### VHF 天线：船与船的直连

每一艘 AIS 设备都配有一根 **VHF 天线**。在海上，VHF 信号可以传播约 **20~30 海里**（约 37~55 公里），这取决于天线高度和天气条件。

在这个范围内，船与船之间可以直接通信：

```
船 A ──── VHF ──── 船 B
      (20~30 海里)
```

这形成了一个**自组织网络**——不需要任何基站参与，两艘船之间就能直接交换 AIS 数据。靠近的船越多，这个网络越丰富。

### 中继接力：把信息传到更远的地方

如果一艘船在深海（离岸几百公里），它的 VHF 信号传不到岸上的基站。那岸上的人怎么知道它在哪？

靠中继：

```
深海船 ──→ 中间船 A ──→ 中间船 B ──→ 岸基基站
   20海里      20海里      20海里
```

深海船的 AIS 广播被中间船 A 收到，船 A 再重新广播出去，船 B 收到后继续转发，最终传回岸上。

这个过程完全自动化，不需要船员做任何操作。每一艘船既是信息的消费者，也是中继节点——跟你之前理解的 **P2P 网络**如出一辙。

### 防冲突机制：不会广播风暴

你可能立刻想到一个问题：如果所有船都在转发，不会乱套吗？

会的。所以 AIS 设计了一套精巧的防冲突机制：

- **延时转发**：收到需要转发的消息后，不立即发出，而是等待一个随机延时（几毫秒到几百毫秒）。这个随机性保证了多艘船不会同时转发同一条消息。
- **侦听抑制**：在转发之前，先侦听一下信道是否空闲。如果检测到其他船正在发送，就再等一下。
- **跳数限制**：每条消息默认只转发 2 次（1 跳 → 2 跳），之后就不再继续。这确保了消息不会在全世界的 AIS 网络里无限循环。

这三重机制保证了：**即使几千艘船在同一个海域，AIS 网络也不会因为中继而崩溃。**

## 三、远海与全球覆盖

### 岸基基站：近海的骨架网络

在沿海和繁忙航道，各国海事部门部署了大量的 **AIS 岸基基站**。这些基站：

- 架设在海岸线的高处（灯塔、山顶、高楼顶）
- VHF 天线覆盖约 **40 海里**（比船对船稍远，因为天线更高）
- 接收到船舶的 AIS 信号后，通过 **光纤、4G/5G 或微波** 上传至海事云计算中心

这些岸基基站不是孤立的。它们通过专网互联，形成一个 **AIS 岸基网络**。你在上海的船舶交管中心（VTS）能看到的船舶位置，就是这张网络汇聚出来的结果。

>

### 卫星 AIS：真正的全球覆盖

岸基基站再密，也只能覆盖离岸几十海里。对于跨洋航行的船舶，需要另一种方案。

这就是 **卫星 AIS**：

- 在 **低轨道（LEO）卫星**（约 600~900 公里高度）上搭载 AIS 接收机
- 卫星过顶时，可以接收到其视野范围内的所有船舶 AIS 信号
- 卫星下传数据到地面站，再接入海事云

一颗低轨道卫星每 90 分钟左右绕地球一圈。通过多颗卫星组网，可以实现**接近实时的全球船舶追踪**。

不过卫星 AIS 也有局限：一颗卫星在同一时刻只能看到一大片海域（直径约 3000~5000 公里），如果这个海域内有上万艘船在同时发送信号，信号会在卫星端互相碰撞。所以卫星 AIS 更适合远海监控，近海密集区域仍然依赖岸基网络。

**综合来看，全球覆盖的链路是这样的：**

```
船舶 ──VHF──→ 附近船舶（船间中继接力）
船舶 ──VHF──→ 岸基基站 ──光纤/4G──→ 海事云
船舶 ──VHF──→ 卫星 ──无线电──→ 地面站 ──光纤──→ 海事云
```

三条路径并存，互为补充。最靠近岸的船舶通过基站上云，深海船舶靠中继或卫星，构一张真正没有死角的全球网络。

## 四、核心技术协议：SOTDMA

讲了这么多，你可能会问：**成百上千艘船都在同一个 VHF 频道上广播，为什么信号不会打架？**

这就涉及到 AIS 最核心的协议——**SOTDMA（Self-Organized Time Division Multiple Access，自组织时分多址）**。

### 把时间切成时隙

SOTDMA 的思想很简单：

- **每 1 分钟** 被分为 **2250 个时隙（time slot）**
- 每个时隙非常短（约 26.6 毫秒）
- 每个时隙里，只有一艘船可以发送数据
- 不同的船使用不同的时隙，互不干扰

想象一下学校食堂的午餐时间：如果所有人同时去窗口打饭，就乱套了。但如果学校把午餐时间分成每 5 分钟一个时段，每个班级只能在指定时段去吃饭，就井井有条。

SOTDMA 做的就是这件事——只不过它不需要管理员分配时段，而是**每艘船自己协商、自己预约**。

### 自组织：没有中心调度

关键在 SOTDMA 的"自组织"三个字：

1. **侦听**：新进入网络的船，先花 1 分钟静默侦听，了解哪些时隙已被占用
2. **预约**：挑选一个空闲的时隙，然后在预约信息中声明："未来 3~7 帧内，我会在第 X 时隙发送"
3. **发送**：在自己预约的时隙里广播 AIS 消息，消息里还包含了"下一个发送时隙是第 X 号"
4. **动态调整**：如果发现其他船也在使用同一个时隙（即碰撞），自动跳转到一个新的空闲时隙

整个过程完全自动化，**没有中心服务器，不需要人工配置，船越多系统越稳定。**

>

### SOTDMA 的优势

| 特性 | 说明 |
|------|------|
| **无中心化** | 不需要岸基基站也能运行，船与船之间自组网 |
| **抗冲突** | 预约机制保证了同一时隙只被一艘船使用 |
| **高容量** | 2250 个时隙 / 分钟，理论上同一海域可容纳数千艘船 |
| **动态适应** | 船舶进出网络时，时隙分配自动调整 |
| **低延迟** | 每艘船每 2~10 秒广播一次（取决于航速），接近实时 |

这套协议非常优雅：**它用"时间分片"替代了"频率分配"，用"自组织"替代了"中心调度"。** 每一艘船不需要问任何人，就能自己找到发送的时机，而且还能保证不和其他船冲突。

## 五、AIS 的局限与挑战

### 1. 信号拥堵

在港口或繁忙海峡（如新加坡海峡、英吉利海峡），可能有上千艘船同时出现在一个 VHF 覆盖区内。此时 2250 个时隙会不够用，导致某些船被迫延后发送，信息更新延迟变大。

### 2. 恶意欺骗

AIS 没有强身份认证机制。一条船可以随意修改自己的 MMSI、船名、位置等信息。现实中确实存在过渔船伪装成货轮、或者海盗关闭 AIS 逃避监控的案例。

国际海事组织（IMO）正在推动更强的 AIS 安全标准，但目前这仍然是一个未完全解决的问题。

### 3. 数据量限制

AIS 每个报文只有 256 比特（最多 168 字节）。它只能传输最基本的信息，无法像现代数据链那样承载图片、文本消息或更丰富的航行信息。

新一代 **VDES（VHF Data Exchange System）** 正在解决这个问题——它在 AIS 基础上扩展了宽带数据通道，可以传输电子海图更新、气象数据、甚至短消息和图片。

## 写在最后

AIS 是一个经常被低估的系统。它不像 GPS 那样家喻户晓，但没有它，现代海上交通几乎无法运转。

你可以把 AIS 理解成：

- **一个永不休息的广播电台**——每一艘船都在 24 小时不间断地广播自己的位置
- **一套自组织的聊天协议**——船与船之间不需要基站就能互相通信
- **一张借力打力的全球网络**——靠中继转发和低轨卫星，把覆盖范围从几十海里延伸到全球

它的核心设计哲学，跟前面聊过的 TCP/IP 和 P2P 网络如出一辙：

> **节点自组织 + 局部知识 + 接力传递 = 一张没有中心的全球信息网。**

希望下次当你在海上航行、或者在船讯网上围观巨轮轨迹时，能想起这篇文章——**每一个跳动的小点背后，都是一套绵延了几十甚至上百公里的 VHF 接力，和一颗悄悄划过天际的低轨道卫星。** 🛰️
